# Timewizzard v1.6.2

This release consolidates the Web Builder foundation and completes the planned v1.6.0 → v1.6.2 roadmap.

## Highlights

- One authoritative runtime version and Web Builder asset manifest.
- Clean HTML shell without legacy separator observers.
- Responsive desktop, laptop, iPad and mobile workspace.
- Posts drawer and Blocks / Edit / Preview task navigation.
- Canonical Components V2 payload validation before publishing.
- Pre-publish review with destination, message and mention information.
- Local crash recovery for unsaved editor work.
- Accessible keyboard controls, visible focus, safe-area dialogs and reduced motion.
- Cross-platform UI contract validation and documented QA matrix.

Existing Builder data, templates, posts, Containers, interactions and storage schema remain compatible.
